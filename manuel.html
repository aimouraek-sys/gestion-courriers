📂 2. Format et chemin des PDF ⚠️ IMPORTANT

⚠️ 📌 RÈGLES OBLIGATOIRES

🔴 Le nom du fichier PDF doit respecter exactement ce format :

NNNNN-JJ-MM-AAAA.pdf

Exemple : 00001-15-01-2024.pdf

Partie Description Exemple
NNN Numéro séquentiel (5 chiffres) 00001, 00002, 00003...
JJ Jour (2 chiffres) 01 à 31
MM Mois (2 chiffres) 01 à 12
AAAA Année (4 chiffres) 2024, 2025...

📁 Chemins de sauvegarde :

📥 Courriers entrants
C:/pdfs/arrives/
📤 Courriers sortants
C:/pdfs/departs/

💡 Astuce : Cliquez sur 📂 Ouvrir le dossier dans un courrier pour copier automatiquement le chemin.

📮 4. Gestion des courriers

  • ➕ Ajouter : Type, Numéro, Date, Expéditeur, Objet → 💾 Sauvegarder
  • 📎 PDF : Format NNN-JJ-MM-AAAA.pdf → extraction automatique
  • ✏️ Modifier : Cliquer sur le courrier → ✏️ Modifier
  • 🗑️ Supprimer : Cliquer sur le courrier → 🗑️ Supprimer

🔎 5. Recherche

  • Onglets : 📥 Entrants / 📤 Sortants / 📋 Tous
  • Filtres : Par numéro, date, expéditeur, mot-clé
  • Tri : Par date, numéro, expéditeur, objet

📊 6. Statistiques

  • Filtrer par date (début / fin)
  • Cliquer sur 📈 Calculer
  • Affiche : Total, Entrants, Sortants, Urgents

📎 7. Export / Import

  • 📎 CSV → Exporter en CSV
  • 📊 Excel → Exporter en Excel
  • 📂 Importer → Importer un fichier Excel/CSV
  • 🖨️ Imprimer → Imprimer la liste
